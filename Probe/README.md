# Force Click 离线验证工具

此工具只验证事件与选区读取，不调用 AI、不保存选中文字、不修改剪贴板。

## 构建与运行

```sh
bash Probe/build.sh
open .build/probe/SelectEnglishProbe.app
```

需要 macOS 与 Xcode Command Line Tools。构建过程先运行手势状态机检查，再编译并临时签名应用。它不是经过公证的发行版本。重编译后系统可能要求重新开启辅助功能权限。

## 实测步骤

1. 打开应用，点击 **授权辅助功能**，在系统设置的“隐私与安全性 → 辅助功能”中允许 SelectEnglishProbe。权限只由你手动开启。
2. 在 TextEdit 输入并选中 `The best way to learn is to keep asking questions.`。
3. 先测试选区读取：在工具的“手动诊断目标”中选择 TextEdit，再切到 TextEdit 选中整句，返回工具点击 **读取指定应用选区**，确认显示完整原文。这一步不证明 Force Click 可用。
4. 点 **清空**，再回到 TextEdit，选中整句，在选区上 Force Click 并完全松开。回到工具检查 **全局事件**与**触发**，以及显示的原文是否仍是整句。重复三次，每次手势应只增加一次 trigger。
5. 在 Safari 或 Chrome 的普通网页中重复步骤 3–4。浏览器、PDF 阅读器和网页控件的支持情况可能不同。
6. 在工具窗口内重按会增加 **本地事件**计数；这只能证明本应用内收到事件。
7. 记录系统“查询”是否同时出现、普通按下是否清掉选区、未用力的点击是否误触发。全局监听不会阻止原应用的查询操作。

如果 GLOBAL 一直为零，即使 LOCAL 有数据也不能判定成功。可先确认系统“触控板 → 光标与点按 → 用力点按和触觉反馈”是否开启。不要把本地事件成功当成跨应用支持。

## v0.2 选区诊断
用户反馈：截图中全局事件为 0，本地事件为 69，所见为 stage 1；另反馈手动读取选区失败，具体错误尚未取得。不能据此确定是权限、焦点、目标应用兼容性或无选区问题，也不能认定 Force Click 跨应用验证通过。

界面现已改为中文，显示版本 v0.2。点击“5 秒后读取选区”会隐藏本工具，倒计时结束时只读取一次当前前台应用；请在这段时间选中目标文本。倒计时状态在工具窗口中显示，工具隐藏期间不会弹窗或抢焦点。结束后从 Dock 返回，记录“辅助功能”“目标应用/焦点角色”和读取状态的完整文字（可隐藏原文）。

辅助功能状态在返回本工具时重新检测实际授权。压力日志与读取结果分别显示；本地压力事件不会覆盖读取结果。重新构建可能导致系统需要重新授权；这只是需检查的条件，尚不是已确认根因。

## v0.3 明确指定手动读取目标
自动化测试曾在准备 TextEdit 选区后得到“ChatGPT 无选中文字”，表明测试期间前台可能被宿主切换；这不是用户失败根因的证明。
手动诊断现有应用下拉菜单：先选 TextEdit，在 TextEdit 选中英文，再返回工具点击“读取指定应用选区”。它读取明确选择的进程，不依赖倒计时结束时的前台。延迟按钮也绑定所选目标。应用退出后需刷新列表。
Force Click 的全局触发仍使用当时的真实前台应用，没有改成固定目标，也没有引入选区轮询、剪贴板或私有 API。

## v0.4 全局重按集成
独立被动 CGEvent 实验已在用户实际 Force Click 时观察到 convertedPressure=192、stage 2=71、每手势去重触发=2。v0.4 将这条监听路径集成到工具：全局原始手势经公开 NSEvent 转换得到压力阶段，进入 stage 2 时捕获当时前台应用，随后由串行工作队列读取该应用选区。回调不等待 AX，也不激活本工具。

界面分别显示原始手势、转换后压力、stage 2 和去重触发数量，以及监听安装/启用状态。这里“全局”表示 session tap 的系统事件流，也包含本工具前台时的事件；对本工具自身的选区请求会明确拒绝。本地 NSEvent 计数仍仅作诊断。

重按触发成功与选区读取成功是两项独立结果。普通按下或系统查询可能清掉原选区，此时会显示“AXSelectedText 为空”，不能宣称整条链路成功。工具不会预先缓存正文或模拟复制。

验证方式：在 TextEdit 选中测试英文，在选区上真实 Force Click 并释放，再回工具检查 stage 2/触发是否增加，以及读取结果是否保留完整选区；浏览器重复同样步骤。完整 AI 实现仍等待集成链路实测。已验证 v0.3 位于 `.build/verified-v0.3/SelectEnglishProbe.app`，不需要打开或注册该备份。
