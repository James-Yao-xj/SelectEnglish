# SelectEnglish 原生应用

当前版本是会调用外部 AI 的菜单栏应用，项目与最新使用说明见[根目录 README](../README.md)。此目录保留历史名称 Probe，不代表当前应用仅做离线验证。

## 构建与运行

```sh
bash Probe/build.sh
open .build/probe/SelectEnglishProbe.app
```

需要 macOS、Force Touch 触控板和 Xcode Command Line Tools。构建会运行离线测试，再编译并临时签名；重编译可能需要重新授权。日常使用请只运行一个应用副本。

## 当前行为与数据

- 启动后只显示菜单栏“译”。辅助功能用于读取选中文字，输入监听仅观察鼠标和触控板手势，不监听全局键盘。
- 在其他应用选中英文后用力点按：读取成功后，若已配置有效接口、模型和密钥，会自动把所选文字发送到用户指定的 HTTPS AI 接口。未配置时只展示原文及设置提示。
- 小浮层依次显示生词的语境词性/释义、整句解释、真实固定表达；点击“重试”会重新请求 AI。同一次运行中相同选区及接口/模型可复用最近一次完成结果。
- 待读取时的后续点击可取消该读取；浮层显示后，外部点击、Esc 或关闭会取消待完成的读取/请求。过期结果不会再显示或发送。点击“收藏”才把原文与分析写入本机收藏文件；自动分析结果不自动保存到磁盘。
- 密钥明文保存在 `~/Library/Application Support/SelectEnglish/Private/api-key`，目录 0700、文件 0600，与仓库分离。旧版升级后需在 AI 设置重新输入一次；不会读取、迁移或删除旧钥匙串项目。
- 应用不修改剪贴板，不记录原文、密钥或接口响应正文日志。图片文字与扫描 PDF 不支持。

## 真正离线的验证

```sh
bash Probe/test.sh
```

测试以 URLProtocol 拦截全部请求，只使用假密钥、临时文件和合成状态；不访问真实服务、用户配置、选区或已保存密钥。包括响应契约、历史收藏、私有文件权限、取消、定位与待读取状态下的点击关闭测试。

单独的 `Probe/Experiments/` 被动事件流实验只输出数字元数据，不读取选区或调用 AI；它与上述完整应用不同。

## 不发送 AI 的手动选区诊断

1. 从菜单栏“译 → 触发与选区状态”打开诊断，按需手动授权辅助功能和输入监听，然后重新启动监听。
2. 在 TextEdit 输入并选中公开测试句 `The best way to learn is to keep asking questions.`。
3. 在诊断窗口选择 TextEdit，点击“读取指定应用选区”。此按钮只读取并显示选区，不自动请求 AI。请核对整句；**不要点击浮层“重试”**，该操作会使用真实已配置服务。
4. 此手动检查不证明 Force Click；物理重按测试是独立步骤，已配置服务时它会自动分析，务必只选择愿意发送的文字。
5. 观察实际授权、监听启用、stage 2/触发计数和 AX 读取状态。系统“查询”可能同时出现或改变选区；这些计数也不等于 AI 成功。

旧版的“清空”“5 秒后读取”及 LOCAL 计数是历史探针控件，当前完整应用已不提供；不要按旧版流程操作。
