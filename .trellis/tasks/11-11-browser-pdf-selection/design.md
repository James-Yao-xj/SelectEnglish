# Design
Read focused AXSelectedText first. Add compatible selection attribute/range extraction and bounded focused PDF viewer search only where supported. Fix process identity at trigger, stop on termination. Bounds on traversal, cycle checks, per-element timeouts/overall budget prevent serialAXqueuehang. No hidden/background tabs/windows or arbitraryselectedtext fromdifferentcontrols; selected ranges must be nonempty, valid and sourced from sameelement. Never fetch whole-document strings as fallback. Native source APIs to verify before implementation. Testadapter preserves productionalgorithm and permits failure/timeout/no-selection coverage without realpermissions.
