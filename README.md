# SelectEnglish

MacBook 原生菜单栏工具：选中英文 → 触控板用力点按 → 中文翻译与表达积累 → 手动收藏。

## 运行

```sh
bash Probe/build.sh
open .build/probe/SelectEnglishProbe.app
```

需要 macOS、Force Touch 触控板与 Xcode Command Line Tools。启动后只有菜单栏“译”，不自动弹出结果。选中文字后用力点按，会在指针附近出现原生词典式小浮层。菜单栏“译 → 触发与选区状态”可授权辅助功能并检查监听。点击浮层外部、按 Esc 或点击 × 可关闭；关闭时取消未完成请求。设置、收藏与诊断从菜单栏打开。

首次运行请在“AI 设置”填写完整 HTTPS `/chat/completions` 接口地址、模型名和 API 密钥。未配置不会发送文字。保存有效配置后，重按会自动分析所选原文；也可点击浮层“重试”。最长 20,000 字符，超时 60 秒。服务需要支持非流式 OpenAI 兼容 chat completions；密钥仅写入系统钥匙串，更换服务域名必须重新输入密钥。

结果依次展示：生词（原词、语境词性和中文释义）→整句解释（译文及简短句意/必要结构说明）→固定表达（释义、用法及例句）。单个词也会解释词性和含义；没有固定表达时明确说明，不强行凑数。点击浮层“收藏”才会保存原文与分析；“我的收藏”可查看及删除。

收藏位于 `~/Library/Application Support/SelectEnglish/notebook.json`。自动分析结果不落盘；收藏文件损坏时保留原文件并阻止覆盖。接口失败不记录响应正文或密钥。

## 验证与限制

`bash Probe/test.sh` 运行手势去重、模拟 HTTP 请求/解析/错误/超时/取消和收藏持久化/删除/损坏保护测试，不发真实网络请求。

本机真实 Force Click 已验证：被动全局手势转换到 stage 2，随后读取 TextEdit 完整 50 字符选区。最终 v0.5 在 Chrome 重按后成功读取 40 字符选区；其他应用仍需实测；系统查询可能同时弹出或改变选区。图片和扫描 PDF 不支持。v0.7 已用公开测试句验证真实 DeepSeek 接口返回，并在小浮窗按新顺序显示生词、整句解释和固定表达。新安装仍需自行配置服务与授权。

当前开发构建临时签名，重编译可能需要重新授权同一个应用。包名和 bundle ID 保留探针身份，以避免无谓更换权限身份。验证过的 v0.4 副本保存在 `.build/verified-v0.4/`；不要同时运行多个副本。

## v0.6 词典式浮层
结果使用约 420 宽、不超过 520 高的原生非激活浮层：简短原文预览、中文翻译和表达在内部滚动，小型重试/收藏/取消/设置/关闭控件。位置取自真正重按时的指针，限制在对应屏幕可用区域；网络返回时围绕同一锚点更新，不居中弹出普通应用窗口。
浮层不激活整个应用；仅成为非激活 key panel 以支持本地 Esc 与复制。没有全局键盘监听。用户显式通过菜单“显示翻译”或应用本地快捷键 Cmd+Shift+T 可打开上次结果，不会重新发送 AI 请求。
测试新增浮层角落、多屏负坐标、屏幕菜单条与锚点稳定性。

## v0.7 学习内容顺序
生词优先选出影响理解的 0–8 个内容词；单词选区会分析该词，缺少语境时不编造句子。固定表达只选原文中真实存在的 0–5 个固定搭配或习惯表达。浮层和收藏使用相同顺序。旧收藏保留原译文与表达，并明确标注当时未包含的生词/句意分析。

## v0.8 响应速度
官方 DeepSeek 地址配合 `deepseek-flash` 或 `deepseek-v4-pro` 时，应用明确关闭深度思考，提示词要求简短的解析与用法，保留生词 → 整句解释 → 固定表达。其他自定义接口不附加 DeepSeek 参数。结果仍为完整生成后显示，实际等待也取决于网络与服务负载。

同一次运行中，再次重按同一选区、且接口与模型未变时，会复用最近一次成功结果；只保留一条在内存中，退出即消失。“重试”始终重新请求。保存设置或删除密钥会清空复用结果。完成后显示本次总耗时及其中 AI 请求秒数，选区诊断显示读取用时。密钥读取在后台进行；系统钥匙串确认期间可取消分析，不会卡住浮窗。取消不会关闭系统确认窗口，需要你自行处理。
