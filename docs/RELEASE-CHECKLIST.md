## 每次正式发布必须记录的实机步骤

使用从 GitHub 下载的最终 ZIP，保留正常 Gatekeeper 和隔离状态，在另一台 Mac 上执行；不能用本机复制包或 CI 虚拟机替代。

- [ ] 填写应用版本/源提交/ZIP SHA256、芯片、macOS、触控板型号。
- [ ] 校验下载文件，解压并移入“应用程序”；首次正常启动，无需关闭系统安全保护。
- [ ] 首次使用指引可读，未配置时不发请求；菜单栏入口、退出行为正常。
- [ ] 辅助功能与输入监控授权可完成；重启后当前进程诊断显示两项访问和监听正常。
- [ ] TextEdit 与浏览器各选一句公开英文，物理重按一次只触发一次，读取完整选区，记录系统词典冲突设置。
- [ ] 生词、整句解释、固定表达顺序正确；简单句允许空生词，单个词始终解释。
- [ ] 服务失败、断网、取消、点击外部和快速切换选区不显示过期内容或反复弹窗。
- [ ] 手动收藏、退出重开、删除所选收藏正常；不误删其他记录。
- [ ] 从上一版升级保留配置和收藏，旧版本退出；关闭/撤销权限有明确提示。
- [ ] 浅色/深色系统、多屏与边角位置下浮层文字可读、不会跑出屏幕。
- [ ] 卸载可撤销权限，默认保留数据；完整清除说明可执行。
