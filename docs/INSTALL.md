# 安装、授权与排错

## 安装包和支持范围

公开候选版本为 v0.10.0-beta.1，下载见[对应发布页](https://github.com/James-Yao-xj/SelectEnglish/releases/tag/v0.10.0-beta.1)。若尚无附件，请等待发布完成。ZIP 内根目录应为 `SelectEnglish.app`。发布包为 Universal（arm64 + x86_64），目标 macOS 13.0+；这是编译兼容目标，不是所有系统、硬件或应用的已验证承诺。

可在下载目录使用发布页的校验文件：

```sh
shasum -a 256 -c SelectEnglish-v0.10.0-beta.1.zip.sha256
```

解压后先退出运行中的旧应用，将应用放入“应用程序”，只保留一个正在运行的副本。升级无需删除用户数据。

当前测试包为临时签名，未完成 Apple 公证，macOS 可能阻止打开；请选择等待正式签名包，或有开发经验时按[贡献指南](../CONTRIBUTING.md)从源码构建。不要关闭 Gatekeeper 或移除隔离标记。正式分发路径说明见 [Apple 官方文档](https://developer.apple.com/macos/distribution/)。

## 首次使用

1. 启动后找到菜单栏“译”，打开首次使用指引。关闭结果浮窗不会退出应用。
2. 在“系统设置 → 隐私与安全性 → 辅助功能”允许 `/Applications/SelectEnglish.app` 读取选区。
3. 在同一隐私页面的“输入监控”允许该应用观察触控板和鼠标手势。若列表没有该项，使用“+”添加正式安装路径的应用。按系统要求退出并重新打开。
4. 在“触发与选区状态”确认当前进程显示已授权、输入监听已允许、监听创建成功且启用。列表开关亮着不等于当前运行副本已获得权限；临时签名更新后可能需要重新确认。
5. “AI 设置”中填写完整 HTTPS chat completions 地址、模型及密钥。先阅读[隐私说明](../PRIVACY.md)：保存后重按会自动向该服务发送选中原文。
6. 在 TextEdit 输入公开测试句 `I like to read books after school.`，选中并用力点按。读取、AI 请求与展示应依次完成；很简单的句子没有生词是正常结果。

## 常见问题

| 现象 | 检查方法 |
|---|---|
| 看不到窗口 | 查看菜单栏“译”；这是菜单栏工具，平时只在重按时显示小浮窗。 |
| 系统词典同时出现 | 在“系统设置 → 触控板 → 光标与点按”中将“查询与数据检测器”设为关闭，保留“用力点按与触感反馈”。系统版本不同文字可能略有差异；不要关闭整个 Force Click。 |
| 重按没有结果 | 检查支持 Force Touch 的硬件、两项权限和诊断中的当前启用状态；授权后使用“重新启动监听”，必要时按系统提示重开应用。 |
| 触发增加，但没有文字 | 目标应用可能未通过辅助功能暴露选区；先用 TextEdit 对比。图片、扫描 PDF 和部分自绘控件不支持。不要把整个文档当作选区兜底。 |
| AI 失败或很慢 | 检查完整接口地址、模型名、额度和网络；超时为 60 秒。关闭浮窗可取消，重试会重新请求并可能计费。 |
| 新旧版本互相干扰 | 退出所有副本，统一使用 `/Applications/SelectEnglish.app`；不要同时运行下载目录和开发构建。 |
| 收藏无法读取 | 保留并备份原文件，再报告脱敏错误；应用会阻止覆盖损坏文件。不要上传完整私人收藏。 |

## 卸载和撤销权限

退出菜单栏应用，在系统隐私设置中撤销其辅助功能和输入监控权限，将应用移入废纸篓即可卸载程序。配置和收藏默认保留，便于重装。

如需清除数据，先备份需要的收藏，再自行删除 `~/Library/Application Support/SelectEnglish/`；这会清除本地密钥和收藏。偏好设置可用 `defaults delete com.selectenglish.probe` 清除，操作前请退出应用。系统备份及早期钥匙串项目不会因此删除。已发送给 AI 的内容按第三方服务政策处理。
