# 浏览器 PDF 选区

此页说明 `fix/browser-pdf-selection` 分支的 **0.10.2 / build 15 候选修复**。已发布的 [v0.10.0-beta.1](https://github.com/James-Yao-xj/SelectEnglish/releases/tag/v0.10.0-beta.1) 安装包不包含这次修复；不要将候选代码的能力视为已发布版本的保证。

## 支持范围

目标是浏览器中**可选择文字**的 PDF。默认通过 macOS 辅助功能接口读取实际选区；仅能在画面上看到文字，不代表应用可以读取。

读取器先检查焦点元素的选中文字，再尝试该元素提供的选区范围或文本标记范围。如果焦点位于可确认的 PDF 容器内，会在这个 PDF 子树中有限查找选区。范围、长度、节点数、调用次数与时间均受限制，跳过工具栏及表单控件。无法取得有效选区时默认明确失败，不把整页文字当作选中内容。

不读取整份文档，也不添加 OCR。扫描件、纯图片 PDF 仍不支持；复制受限文件不保证可用，也不会绕过其权限或 DRM。Safari 的 PDF 行为尚未完成本轮实测，Chrome 的候选版本物理重按结果也需单独核对。

## 可选复制兼容

部分自定义网页 PDF 阅读器能选中文字，但不通过辅助功能暴露文本。0.10.2 候选版在设置中提供默认关闭的浏览器复制兼容；自行开启后，仅在物理重按来源为受支持浏览器、辅助功能读取失败时，才尝试复制选区并取得文本。手动选区诊断不触发此功能。

复制前备份剪贴板全部可备份项目；无法完整备份则在修改前停止。随后临时清空剪贴板，触发浏览器复制，读取文本，并在剪贴板仍属于本次操作时尝试恢复。若用户或其他程序同时复制，应用尽力避免覆盖新内容，但不能保证完全恢复。剪贴板管理器或同步工具可能保留这些变化；详细数据边界见[隐私说明](../PRIVACY.md)。

## 如何验证

1. 统一运行候选版 `/Applications/SelectEnglish.app`，确认辅助功能授权、输入监听访问及监听启用正常。
2. 在浏览器打开公开、可选择文字的 PDF，先选中一句简短英文，避免选中地址栏、搜索框或批注输入框。
3. 从“译 → 触发与选区状态”选择该浏览器，使用“读取指定应用选区”，核对返回内容与选区完全一致。此按钮不自动调用 AI。
4. 再回到同一 PDF 重新选中文字，物理重按并松开，核对触发、完整读取及浮窗展示。已配置服务时，这一步会自动发送选中文字；请只用愿意发送的公开例句。

手动读取通过不能替代物理重按验证；检测到重按也不等于成功读取选区。遇到失败时先用 TextEdit 对比权限，再记录应用版本、浏览器版本、公开 PDF 地址、是否能选中文字及脱敏错误提示。不要提供私人 PDF、密钥或完整私人选区。
