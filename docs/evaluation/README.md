# 六级筛选专项评估

`cet6-cases.json` 是维护者编写的公开合成例句，不来自用户选区或官方词表。用于检查当前“面向六级读者”的提示词行为；候选词只是人工审阅提示，不是必须全部返回的答案，也不证明六级词表归属。

## 执行和记录

离线测试只能验证结构约束，不能判断模型筛词质量。真实模型评估由使用者在应用中配置自己的接口，逐例选择公开原文并重按或重试；记录日期、版本/源提交、提供商、模型、提示词版本、返回结果和耗时。不要记录或上传密钥。空输入用于确认不发送请求，不要求模型返回空句翻译。

同一例句建议用“重试”独立请求三次，避免内存结果复用影响观察。结果会随模型、服务版本变化，单次观察不能代表整体质量。本轮真实样例记录由维护者另存于本目录，未执行项明确留空。

## 人工评分规则

逐例给每项 0（错误）、1（部分符合）、2（符合），并写一句依据：

1. **筛选克制**：简单句不列基础词、不为凑数添加词；没有生词可接受。
2. **来源与语境**：词形来自原文，词性和中文义对应当前语境；单词查询包含所选词本身，不杜撰上下文。
3. **难度与价值**：对六级阅读者有学习价值，专业术语、少见义优于普通基础词。存在主观边界时记录争议，不硬判词表身份。
4. **整句理解**：中文准确、不漏否定/限定，结构解析简短且有必要。
5. **固定表达**：只列原文真实搭配或惯用表达，无则空；中文义和例句正确。

结构要求：生词 0–8 个，固定表达 0–5 个，词条有原词/词性/中文义，整句字段齐全。结构正确和语义评分分别记录。若汇总，注明案例数、请求次数、失败/超时数和人工判分方式，不把本小样本百分比称为产品准确率。

发布前优先修复：无关词条、单词漏解释、整句误译、基础词泛滥、编造固定表达。增加新用例时保持公开、合成且无个人信息。
